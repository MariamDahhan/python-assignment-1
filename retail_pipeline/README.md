Retail Analytics Data Ingestion & Transformation Pipeline
Description
This project processes retail transaction data and converts raw transaction records into useful business insights.

Problem Solved
Retail businesses often receive transaction data that contains missing or invalid information. This project validates, cleanses, and transforms the data before generating reports.

Features
Transaction validation
Data cleaning
Total sales calculation
Top-performing branch detection
Customer tier breakdown
Functional programming using map(), filter(), and lambda
Unit testing
Data Used
The project works with retail transaction records containing:

Branch ID
Transaction Date
Customer Tier
Item Count
Revenue
How to Run
Open a terminal
Navigate to the retail_pipeline folder
Run:
python main.py
